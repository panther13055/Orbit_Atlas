# Orbit Atlas

Interactive editorial/science website about Earth's orbital environment and space debris.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The app lives at the repository root so Vercel detects Vite directly. The site deliberately labels numerical figures as report snapshots, not live telemetry.

## Included
- Interactive orbit scene with clickable object types
- Searchable debris/object explorer
- ESA + ISRO snapshot statistics
- Conceptual orbital-path interaction
- Kessler Syndrome explainer
- India / ISRO orbital-safety section
- Cleanup and prevention section
- Official source links
- Responsive mobile navigation
- 60-second guided tour
